Choose a project in the app, then use local Studio in your browser to define a task, inspect the candidate and decide what to deliver. The app includes Parallax’s Python runtime. Your project tools and provider accounts are separate setup steps.

Open your project

  1. For an accepted download, drag Parallax Beta into Applications before starting tasks. Keep the app at that location.
  2. Select Choose folder and choose an existing Git repository with meaningful tests. Selecting a folder does not start agents.
  3. Select Open local Studio. Keep the app open while work runs. Open Studio reopens the same session.

Connect your agents

Open Connections in Studio. Use your installed, signed-in coding-agent CLIs, or select API key to save a provider key in macOS Keychain. The desktop app does not inherit keys exported in a terminal; environment-variable credentials are unavailable through this launcher.

Select usable providers for implementation and independent review in the task’s team settings. Provider usage limits and charges remain yours. A detected sign-in does not establish remaining quota.

Make your first task small

Choose one bug whose behavior you can verify. In New task, select Verified change, open Configure team, task instructions, and checks, and set your real check commands and acceptance criteria.

Stop, recover and update

Closing a browser tab leaves Studio running. Stop local Studio stops active work and retains its evidence. Quitting a running app asks whether to stop or keep working. Use Show Parallax in the app menu to reopen the launcher window.

Saved state lives separately for each project under ~/Library/Application Support/Parallax/Beta/projects/. Reopen the same project to inspect recovered work. Recovery does not reset its consumed execution budget.

Stop work and quit before replacing the app at the same installed path. There is no automatic updater. Moving an app with provisioned Python task environments can block startup because their saved interpreter links reference its previous location. Preserve that state for recovery; do not edit its links or identity file. A signed task-interpreter policy for native Python dependencies still needs validation.

Your data and support

Local Studio listens on this Mac’s loopback interface. Keep launch links and state directories private. The app does not automatically pair or share your Mac. Selected agents and model providers may receive project context during a task, according to their configuration.

Use the Parallax issue tracker for a sanitized report: app version, macOS version, architecture and a description of the failure. Exclude provider keys, launch tokens and private code. No report is sent automatically.

## Project update

When I delegate a code change, I still need to read the patch and check what ran. Parallax puts that result in one task view: the diff, independent review, recorded check output and my approval decision.

The 1.4 development preview keeps the candidate separate from my project until I approve and apply it. If it needs a correction, the revision gets fresh checks and review. It uses the provider accounts and machine I already have.

I'm focusing on one first task that someone can finish from installation through approval and local application. The bundled exercise starts with a failing empty-input test and keeps those tests unchanged through the fix. It is a setup exercise; I haven't measured productivity gains from it.
